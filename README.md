# Sistema de Restaurante

## Integrante
Breno Bernardes Motta

## Sobre
Projeto em TypeScript com classes, construtores, herança, arrays e padrão Repository. Os arquivos ficam organizados nas pastas `models` e `repositories`. Não usa `import` nem `export`, conforme a proposta de usar conceitos básicos vistos em aula.

## Como executar
1. Instale o Node.js.
2. Abra esta pasta no VS Code.
3. No terminal, execute um comando por vez:

   ```bash
   npm install
   npm run build
   npm start
   ```

Os dados são exemplos guardados em arrays na memória.
